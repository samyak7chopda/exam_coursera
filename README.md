# Simple Interest Calculator (Python)

Project Overview
This project is a simple Python program that calculates **Simple Interest (SI)** based on user inputs for **Principal (P)**, **Rate of Interest (R)**, and **Time (T)**.  
It demonstrates basic input handling, arithmetic operations, and output formatting — ideal for beginners learning Python fundamentals.

Formula Used

\[
\text{Simple Interest} = \frac{P \times R \times T}{100}
\]

Features
- Takes user input for principal, rate, and time  
- Calculates simple interest using the standard formula  
- Displays the result in a clear format  
- Easy to extend for compound interest or GUI-based versions  

Example
Input:
Enter Principal: 1000
Enter Rate of Interest: 5
Enter Time (in years): 2

Output:
Simple Interest = 100.0
